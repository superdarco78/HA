# 📝 Historia zmian – Blokada kafelka

## v6

Pewniejsze znajdowanie karty przy zapisie (kolejność kluczy, karty, które same zmieniają swoją konfigurację).

## v5

Przytrzymaj dowolną kartę 3 s (bez trybu edycji) = menu „Dodaj blokadę”. Menu kłódki też po 3 s.

## v4

Wspólne ustawienia domyślne dla wszystkich kłódek (pulpit „🔒 Blokady”, karta `custom:blokada-ustawienia`). Karta zapisuje tylko to, czym różni się od wspólnych ustawień.

## v3

Uniwersalna blokada dowolnej karty: odblokowanie przytrzymaniem, dwuklikiem, PIN-em albo potwierdzeniem; menu kłódki (odblokuj, przesuń, ustawienia, wyłącz na 1 h, zdejmij); przycisk „Dodaj / Zdejmij blokadę” w trybie edycji pulpitu.

## v2

Pełna blokada kafelka z kłódką: przytrzymaj = odblokuj, odliczanie i automatyczna blokada, przesuwanie kłódki.

## v1

Pierwsza wersja.
